# BootHarbor branding

App name approved by Naeem Asghar: **BootHarbor — Windows & Linux USB Creator**.

Naeem selected his connected GitHub profile picture for the app icon.
`NaeemGitHubAvatar.png` is the original profile image retrieved from
https://avatars.githubusercontent.com/u/320038852?v=4 .
`BootHarborIcon.png` is the AI-assisted icon treatment made from that reference,
with a restrained teal/slate rounded tile and a small USB flash-drive badge.

The app links to the verified profile https://github.com/sirnaeemasghar .
The profile portrait and app icon are branding assets supplied/approved by the
project owner; no independent photography-rights verification has been performed.
Fork authors should identify their own fork clearly and avoid implying endorsement
by Naeem. Application code is GPL-3.0-or-later; retain license and attribution notices.

Generate all macOS icon sizes and the ICNS file with `scripts/generate-icon.sh`.
The source portrait and icon are included so the source package builds offline.
